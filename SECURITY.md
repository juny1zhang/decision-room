# 安全问题 · Security

如果发现本地访问凭证可被绕过、讨论记录泄露或 CLI 能执行超出所选权限的操作，请向维护者提交私密报告。[私密报告安全漏洞](https://github.com/juny1zhang/decision-room/security/advisories/new)

请写明项目版本或提交、操作系统、涉及的 CLI 版本、复现步骤和观察到的影响。示例请使用虚构的问题和账号。终端启动地址中 `#` 后的内容是访问凭证，分享日志或截图前请移除它，以及任何账号令牌和私人对话。

调试模式（`--debug` 或 `DECISION_ROOM_DEBUG=1`）的输出不含问题和回答，其中的密钥、令牌和邮箱地址也会被隐藏，但仍可能包含本机路径、用户名和 CLI 错误信息的片段。附上之前请逐行检查。

Report vulnerabilities privately through [GitHub Security Advisories](https://github.com/juny1zhang/decision-room/security/advisories/new). Include the commit or release, OS, CLI versions, reproduction steps and observed impact. Use synthetic examples and redact the startup URL fragment, account tokens and personal discussion content. Debug output (`--debug` or `DECISION_ROOM_DEBUG=1`) leaves out questions and answers and hides keys, tokens and e-mail addresses, but it can still contain local paths, your user name and fragments of CLI error messages, so review it line by line before you attach it.
